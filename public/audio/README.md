# ไฟล์เสียงของเกม

ตอนนี้เกม **เล่นได้ครบทุกส่วนโดยไม่ต้องมีไฟล์เสียง** — เสียงทุกชิ้น (ฝีเท้า คาถา ศัตรู
บรรยากาศ และเพลงประกอบ) ถูกสังเคราะห์สดจาก Web Audio API เพื่อใช้เป็นเสียงชั่วคราว

## วิธีใส่เสียงจริง

1. วางไฟล์ (`.mp3`, `.ogg`, `.wav`, `.webm`) ไว้ในโฟลเดอร์ `public/audio/`
2. เปิด `public/audio/manifest.json` แล้วใส่คีย์ที่ต้องการแทนที่:

```json
{
  "sounds": {
    "step_dirt": "steps/dirt-01.mp3",
    "spell_flame": "spells/flame-toll.ogg",
    "music_explore": "music/wiranlaya-theme.mp3"
  }
}
```

3. รีเฟรชหน้าเกม — คีย์ที่ประกาศไว้จะใช้ไฟล์จริง คีย์ที่เหลือยังใช้เสียงสังเคราะห์ต่อไป
   (ผสมกันได้ ไม่ต้องแทนที่ทีเดียวทั้งหมด)

## คีย์เพลงประกอบ

| คีย์ | ใช้เมื่อ |
| --- | --- |
| `music_explore` | เดินสำรวจทั่วไป |
| `music_tense` | อยู่ในพื้นที่ที่มีศัตรู |
| `music_boss` | ต่อสู้กับมหาเงียบ |

## คีย์เสียงทั้งหมด

ดูรายชื่อคีย์ที่ระบบรู้จักได้จาก `public/src/audio/synth-bank.js` (ตัวแปร `SOUND_SPECS`)
หรือเรียก `window.wiranlaya.audio.placeholderKeys()` ในคอนโซลของเบราว์เซอร์
เพื่อดูว่าคีย์ไหนยังใช้เสียงสังเคราะห์อยู่

## ข้อแนะนำสำหรับเสียงที่จะอัปโหลด

- **โมโน** สำหรับเสียงที่ต้องวางตำแหน่งสามมิติ (ฝีเท้า ศัตรู จุดสังเกต) เพราะ
  `PannerNode` จะจัดตำแหน่งซ้าย-ขวาให้เอง ไฟล์สเตอริโอจะทำให้ทิศทางเพี้ยน
- **สเตอริโอ** ใช้ได้กับเพลงประกอบและเสียงบรรยากาศกว้าง ๆ
- ตัดความเงียบหัว-ท้ายออก เพื่อให้เสียงตอบสนองทันทีที่ผู้เล่นออกคำสั่ง
- ปรับความดังให้ใกล้เคียงกัน (ประมาณ -18 dBFS) ระบบมีคอมเพรสเซอร์ท้ายสายอยู่แล้ว
