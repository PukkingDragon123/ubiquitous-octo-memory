# วิรัลยา: เสียงสะท้อน (Wiranlaya: Echo)

เกม RPG แฟนตาซีเวทมนตร์ **ภาษาไทย** แบบ **Audio-First** ที่ออกแบบให้ผู้พิการทางสายตา
เล่นจบได้ด้วยการฟังและการพูดล้วน ๆ และผู้พิการทางการได้ยินก็เล่นจบได้ด้วยคำบรรยาย
ภาพ และการสั่น — โดยไม่ต้องมีเวอร์ชันแยกสำหรับใคร

> โลกกำลังเงียบลงทีละเสียง ระฆังทั้งสามใบหยุดดัง
> และคุณคือ "ผู้ฟัง" คนสุดท้ายที่ยังได้ยินโลกหายใจ

---

## เริ่มเล่นใน 30 วินาที

```bash
git clone <repo-url>
cd ubiquitous-octo-memory
npm start          # ไม่ต้อง npm install — โปรเจกต์นี้ไม่มี dependency เลย
```

เปิด <http://localhost:5173> แล้วกด **“เริ่มการเดินทาง”**

- แนะนำ **Chrome หรือ Edge** (รองรับการรับเสียงภาษาไทยผ่าน Web Speech API)
- แนะนำให้ใส่ **หูฟังสเตอริโอ** เพื่อให้ระบบเสียงสามมิติทำงานเต็มที่
- ถ้าไม่สะดวกใช้เสียง เล่นด้วย **แป้นพิมพ์** หรือ **ช่องพิมพ์คำสั่ง** ได้ครบทุกคำสั่ง

## เล่นยังไง

พูดคำสั่งภาษาไทยออกมาตรง ๆ (กดปุ่ม **เว้นวรรค** ค้างไว้ขณะพูด หรือเปลี่ยนเป็นโหมดฟังตลอดเวลาได้ในหน้าตั้งค่า)

| อยากทำอะไร | พูดว่า |
| --- | --- |
| เดิน | “เดินหน้า”, “เดินสามก้าว”, “ถอยหลัง” |
| หันตัว | “เลี้ยวซ้าย”, “เลี้ยวขวา”, “หันหลัง”, “หันไปทางเหนือ” |
| ฟังสภาพแวดล้อม | “สำรวจ”, “ฟังรอบตัว”, “ฉันอยู่ที่ไหน” |
| จับทิศศัตรู | “หันไปทางเสียง” |
| อ่านค่าสถานะ | “สถานะ”, “พลังชีวิตเหลือเท่าไหร่” |
| ร่ายคาถา | พูดชื่อคาถา เช่น “เพลิงกังวาน”, “แสงสมาน”, “ระลอกสำรวจ” |
| คุยกับผู้คน | “คุยกับยายมาลี”, แล้วพูดคุยต่อได้อิสระ |
| ขอให้วิสป์นำทาง | “ไปทางไหนต่อ”, “พาไปถ้ำสะท้อน” |
| ถามอะไรก็ได้ | “วิสป์ มหาเงียบคืออะไร” |
| อื่น ๆ | “เก็บของ”, “ใช้ขวดน้ำกังวาน”, “ตีระฆัง”, “หนี”, “บันทึกเกม”, “ช่วยด้วย” |

รายการเต็มอยู่ใน [`docs/VOICE-COMMANDS.md`](docs/VOICE-COMMANDS.md)

**ตัวรู้จำเสียงไม่ต้องถอดเสียงถูกเป๊ะ** — ระบบเทียบคำแบบไม่สนวรรณยุกต์และยอมให้มีคำห้อยหน้า-หลัง
เช่น “ขอร่ายคาถาเพลิงกังวาลหน่อย” ก็ยังร่าย *เพลิงกังวาน* ได้

## จุดเด่นด้านการเข้าถึง

**สำหรับผู้พิการทางสายตา**

- **เสียงสามมิติจริง (HRTF)** — ทางออก จุดสังเกต และศัตรู มีตำแหน่งของตัวเองในสนามเสียง
- **เสียงฝีเท้าแยกตามพื้น** — ดิน ไม้ หิน ใบไม้ มอสส์ กรวด เถ้า บอกได้ว่าเดินอยู่ที่ไหน และยืนยันว่าคำสั่งถูกรับแล้ว
- **ภูตนำทาง “วิสป์”** — บอกทางเป็นเลี้ยวซ้าย-ขวาและจำนวนช่วงทาง อ่านค่าสถานะ และตอบคำถามเกี่ยวกับโลก
- **คาถา “ระลอกสำรวจ”** — โซนาร์ในเกม บอกผังห้อง ทางออก และของที่ซ่อนอยู่
- **การต่อสู้ด้วยหู** — ต้องหันหน้าเข้าหาเสียงก่อนร่ายคาถา (มี “โหมดช่วยเล็ง” เปิดไว้เป็นค่าเริ่มต้น)
- **การสั่นบอกทิศและเหตุการณ์** — แต่ละคาถา แต่ละอันตราย มีจังหวะสั่นเฉพาะตัว
- ทั้งเกมเล่นได้ด้วยแป้นพิมพ์ และหน้าเว็บมีโครงสร้าง ARIA ครบสำหรับ screen reader

**สำหรับผู้พิการทางการได้ยิน**

- **คำบรรยายทุกเสียง** ไม่ใช่แค่บทพูด — เสียงประกอบมีคำบรรยายพร้อม **ลูกศรบอกทิศและระยะ**
- **เรดาร์ภาพ** แสดงทางออก จุดสังเกต และตำแหน่งศัตรูรอบตัวแบบเรียลไทม์
- **ตัวแสดงจังหวะการสั่นเป็นภาพ** ใช้แทนช่องทางเสียงได้ทั้งหมด
- แถบพลัง รายการคาถาพร้อมเลขปุ่ม และสถานะศัตรู แสดงบนจอตลอดเวลา
- โหมดคอนทราสต์สูง ตัวอักษรใหญ่ และลดการเคลื่อนไหว

รายละเอียดการออกแบบอยู่ใน [`docs/ACCESSIBILITY.md`](docs/ACCESSIBILITY.md)

## เสียงและเพลง (ตอนนี้เป็นเสียงชั่วคราว)

เสียงทุกชิ้นในเกม — ฝีเท้า คาถา ศัตรู บรรยากาศ และเพลงประกอบ — **สังเคราะห์สดจาก Web Audio API**
เพื่อให้เกมเล่นได้ทันทีโดยไม่ต้องรอไฟล์เสียง

เมื่อมีไฟล์เสียงจริงแล้ว วางไฟล์ใน `public/audio/` แล้วประกาศคีย์ใน `public/audio/manifest.json`
ระบบจะสลับไปใช้ไฟล์จริงทันที (ผสมกับเสียงสังเคราะห์ได้ ไม่ต้องแทนที่ทีเดียวทั้งหมด) —
ดูวิธีทำใน [`public/audio/README.md`](public/audio/README.md)

## AI ในเกม

- **วิสป์** และ **NPC** ทุกตัวมี "สมองในเครื่อง" ที่ทำงานได้เต็มรูปแบบแบบออฟไลน์
  (จับคู่เจตนา ฐานความรู้ประจำตัว ความจำบทสนทนา และการหาเส้นทางแบบ BFS)
- ถ้าต้องการให้ตอบได้อิสระขึ้น ใส่ endpoint ของโมเดลภาษาเองได้ในหน้าตั้งค่า
  เมื่อเชื่อมต่อไม่ได้หรือหมดเวลา ระบบจะถอยกลับไปใช้สมองในเครื่องอย่างเงียบ ๆ
- **ไม่มีคีย์ API ฝังอยู่ในซอร์สโค้ด** ค่าที่กรอกเก็บไว้ใน `localStorage` ของเครื่องผู้เล่นเท่านั้น

## โครงสร้างโปรเจกต์

```
public/
  index.html                หน้าเกม (โครงสร้าง ARIA ครบ)
  styles/main.css           ธีมคอนทราสต์สูง + โหมดตัวอักษรใหญ่
  audio/                    ที่วางไฟล์เสียงจริง + manifest.json
  src/
    main.js                 ตัวควบคุมหลัก เชื่อมทุกระบบเข้าด้วยกัน
    core/                   ข้อความภาษาไทย (จับคู่แบบทนการถอดเสียงผิด), สุ่มแบบมี seed, event bus
    world/                  โลก ตัวละคร ศัตรู ของ เควส และระบบคาถา (ข้อมูลล้วน)
    game/                   เอนจินเกม, ตัวแปลคำสั่งเสียง, ตัวส่งคำสั่งกลาง
    ai/                     สมองของวิสป์, สมองของ NPC, ตัวเชื่อม LLM (ไม่บังคับ)
    audio/                  เอนจินเสียงสามมิติ, คลังเสียงสังเคราะห์, TTS ไทย, ฝีเท้า, เพลง
    input/                  รับเสียงพูด และแป้นพิมพ์
    haptics/                รูปแบบการสั่น
    ui/                     คำบรรยาย, HUD/เรดาร์, การตั้งค่าการเข้าถึง
server/dev-server.mjs       เซิร์ฟเวอร์สแตติกไร้ dependency
tests/                      ชุดทดสอบ node --test (96 เคส รวมถึงการเล่นจนจบเกม)
docs/                       เอกสารโลก การเข้าถึง และคำสั่งเสียง
```

เอนจิน ตัวแปลคำสั่ง และสมอง AI เป็นโมดูลบริสุทธิ์ (ไม่แตะ DOM) จึงทดสอบได้ทั้งหมดด้วย Node

## การทดสอบ

```bash
npm test     # ชุดทดสอบทั้งหมด รวมถึงการเล่นจนจบเกมด้วยคำสั่งเสียงล้วน ๆ
npm run lint # ตรวจไวยากรณ์ทุกไฟล์ (ไม่ต้องติดตั้งอะไรเพิ่ม)
```

ชุดทดสอบครอบคลุมถึงเรื่องที่สำคัญกับการเข้าถึงโดยตรง เช่น
"ทุกเหตุการณ์เสียงต้องมีคำบรรยายกำกับ", "คาถาทุกบทต้องมีจังหวะสั่นที่ไม่ซ้ำใคร",
"ศัตรูทุกตัวต้องมีคาถาที่รับมือได้จริง" และ "เล่นจบเกมได้แม้ผู้เล่นออกเสียงไม่ชัด"

## ความเป็นต้นฉบับ

โลก ตัวละคร สิ่งมีชีวิต ระบบเวทมนตร์ และชื่อคาถาทั้งหมดถูกออกแบบขึ้นใหม่สำหรับโปรเจกต์นี้
ไม่ได้คัดลอกหรือดัดแปลงจาก Harry Potter, Dungeons & Dragons หรืองานของผู้อื่น
แนวคิดหลักคือ "เวทมนตร์คือเสียง" — เวทเกิดจากการเปล่งเสียงจนสสารรอบตัวสั่นพ้อง
ซึ่งเป็นระบบที่ออกแบบมาให้เข้ากับการเล่นด้วยเสียงโดยเฉพาะ
รายละเอียดโลกอยู่ใน [`docs/WORLD.md`](docs/WORLD.md)
