# บันทึกการออกแบบเพื่อการเข้าถึง

หลักการเดียวของโปรเจกต์นี้: **เกมเดียว เล่นได้ทุกคน**
ไม่มี "โหมดคนตาบอด" แยกต่างหาก เพราะโหมดแยกมักถูกดูแลน้อยกว่าและตามหลังเสมอ

## ช่องทางรับรู้สามทาง เนื้อหาเดียวกัน

ทุกเหตุการณ์ในเกมถูกส่งออกเป็น "เหตุการณ์" กลาง แล้วแปลเป็นสามช่องทางพร้อมกัน

| เหตุการณ์ | เสียง | ภาพ | สัมผัส |
| --- | --- | --- | --- |
| เดินหนึ่งก้าว | ฝีเท้าตามชนิดพื้น สลับซ้าย-ขวา | คำบรรยาย “เสียงฝีเท้าบนพื้นดิน” | สั่นสั้นหนึ่งครั้ง |
| ศัตรูเข้าใกล้ | เสียงมันจากทิศจริง ดังขึ้นเรื่อย ๆ | จุดแดงบนเรดาร์ + ลูกศรบอกทิศ | จังหวะสั่นตามทิศ |
| ร่ายคาถา | เสียงเฉพาะของคาถา | ชื่อคาถาในคำบรรยาย | จังหวะสั่นเฉพาะของคาถานั้น |
| ชนกำแพง | เสียงกระแทก | คำบรรยาย “ชนกำแพง” | สั่นสองจังหวะ |
| ปลุกระฆัง | ระฆังกังวานยาว | แจ้งภารกิจคืบหน้า | จังหวะสั่นยาวสามชุด |

การทดสอบอัตโนมัติบังคับกฎนี้ไว้: มีเทสต์ที่ล้มเหลวทันทีถ้ามีเหตุการณ์เสียงใดไม่มีคำบรรยาย
และมีเทสต์ที่บังคับว่าจังหวะการสั่นของแต่ละเหตุการณ์ต้องไม่ซ้ำกัน

## สำหรับผู้พิการทางสายตา

**เสียงเป็นข้อมูล ไม่ใช่บรรยากาศ**
เสียงทุกชิ้นวางตำแหน่งด้วย `PannerNode` แบบ HRTF ผู้เล่นแยกได้ว่าน้ำหยดอยู่ทางซ้าย
ระฆังอยู่ข้างหน้า และซากหินคำรามกำลังเดินมาจากเฉียงขวาหลัง

**การต่อสู้ที่ใช้หูเป็นเป้าเล็ง**
ต้องหันหน้าเข้าหาเสียงก่อนร่ายคาถา ถ้าหันผิดคาถาจะเฉี่ยว วิสป์จะบอกทันทีว่าเสียงอยู่ทางไหน
คำสั่ง "หันไปทางเสียง" จัดทิศให้อัตโนมัติ และ **โหมดช่วยเล็ง (เปิดไว้เป็นค่าเริ่มต้น)**
ยอมให้คลาดได้ถึง 90 องศา ผู้เล่นใหม่จึงไม่ติดตั้งแต่ด่านแรก ส่วนผู้เล่นที่อยากท้าทายปิดได้

**ไม่มีทางหลงทาง**
- คาถา *ระลอกสำรวจ* ทำหน้าที่เป็นโซนาร์ บอกผังห้องและของที่ซ่อนอยู่
- วิสป์บอกทางเป็น "เลี้ยวซ้ายก่อน แล้วมุ่งไปทางตะวันตก อีกสองช่วงทาง" ไม่ใช่พิกัดบนแผนที่
- พูดว่า "ไปทางไหนต่อ" ได้ทุกเมื่อ ระบบคำนวณเส้นทางสั้นที่สุดจากตำแหน่งจริง

**ตัวเลขถูกอ่านเป็นคำ**
"พลังชีวิต หนึ่งร้อยสี่สิบเจ็ด" ฟังรู้เรื่องกว่าตัวเลขดิบเมื่อผ่านเสียงอ่าน

**เสียงพูดมีลำดับความสำคัญ**
ข้อความเร่งด่วน (ศัตรูโจมตี พลังชีวิตเหลือน้อย) แทรกคิวได้ทันที ไม่ต้องรอประโยคบรรยายจบ

## สำหรับผู้พิการทางการได้ยิน

- **คำบรรยายครอบคลุมเสียงประกอบ** ไม่ใช่แค่บทพูด และมีลูกศร (⬆️ ➡️ ⬇️ ⬅️) กับระยะเป็นก้าวกำกับ
- **เรดาร์** แสดงทางออก จุดสังเกต และศัตรูรอบตัว โดยผู้เล่นอยู่กลางและหันขึ้นเสมอ
- **ตัวแสดงการสั่นเป็นภาพ** ทำให้จังหวะสั่นอ่านได้ด้วยตา แม้อยู่บนเครื่องที่สั่นไม่ได้
- ทุกอย่างที่ตัดสินผลแพ้ชนะ (ทิศศัตรู ระยะ พลังชีวิต) อยู่บนจอตลอดเวลา ไม่ต้องพึ่งการฟัง

## สำหรับผู้พิการทางการเคลื่อนไหวและกรณีอื่น

- ทุกคำสั่งมีทางเลือกอย่างน้อยสามทาง: **เสียง / แป้นพิมพ์ / ช่องพิมพ์**
- โหมดไมโครโฟนเลือกได้ระหว่าง "กดค้างเพื่อพูด" กับ "ฟังตลอดเวลา" สำหรับผู้ที่ใช้มือลำบาก
- ไม่มีคำสั่งใดต้องกดพร้อมกันหลายปุ่ม หรือต้องตอบสนองภายในเวลาจำกัด
- ไม่มีการกระพริบถี่ และมีโหมดลดการเคลื่อนไหว

## เมื่อสิ่งต่าง ๆ ใช้ไม่ได้

ระบบทุกตัวมีทางถอย และจะ**บอกผู้เล่นเป็นภาษาไทยว่าเกิดอะไรขึ้นและทำอะไรได้ต่อ**

| ใช้ไม่ได้ | เกมทำอะไรแทน |
| --- | --- |
| ไม่มีเสียงอ่านภาษาไทยในเครื่อง | แจ้งเตือน แล้วใช้คำบรรยายเต็มรูปแบบ |
| เบราว์เซอร์รับเสียงพูดไม่ได้ | แนะนำแป้นพิมพ์และช่องพิมพ์คำสั่ง |
| ยังไม่ได้อนุญาตไมโครโฟน | บอกวิธีอนุญาตอย่างชัดเจน |
| อุปกรณ์สั่นไม่ได้ | แสดงจังหวะสั่นเป็นภาพและข้อความแทน |
| ไม่มีไฟล์เสียงจริง | ใช้เสียงสังเคราะห์ทั้งหมด เกมยังเล่นจบได้ |
| ต่อโมเดลภาษาไม่ได้ | วิสป์และ NPC ใช้สมองในเครื่องต่อทันทีโดยไม่สะดุด |

## โครงสร้างหน้าเว็บ

- `lang="th"` และหัวข้อเรียงลำดับถูกต้อง
- คำบรรยายอยู่ใน `role="log"` + `aria-live="polite"` — screen reader อ่านตามได้โดยไม่ถูกขัดจังหวะ
- แถบพลังใช้ `role="progressbar"` พร้อม `aria-valuenow`/`aria-valuemax` ที่อัปเดตจริง
- เรดาร์มี `aria-label` อธิบายหน้าที่ ไม่ใช่แค่ "canvas"
- มีลิงก์ข้ามไปช่องพิมพ์คำสั่ง และเส้นโฟกัสหนาชัดทุกองค์ประกอบ
