# คำสั่งเสียงทั้งหมด

พูดออกมาเป็นประโยคธรรมชาติได้ ระบบจะจับใจความเอง
ตัวรู้จำเสียงไม่ต้องถอดถูกเป๊ะ — การเทียบคำไม่สนวรรณยุกต์และยอมให้มีคำห้อยหน้า-หลัง

## เคลื่อนที่

| พูดว่า | ผล |
| --- | --- |
| เดินหน้า / เดินไปข้างหน้า / เดิน | เดินไปข้างหน้าหนึ่งช่วง |
| เดินสามก้าว / เดินหน้าห้าก้าว | เดินตามจำนวนที่บอก (สูงสุดห้า) |
| ถอยหลัง / ถอย | เดินย้อนกลับ |
| เดินไปทางซ้าย / เดินไปทางขวา | เดินด้านข้าง |
| เลี้ยวซ้าย / หันซ้าย | หันตัว 90 องศา |
| เลี้ยวขวา / หันขวา | หันตัว 90 องศา |
| หันหลัง / กลับหลังหัน | หันกลับ 180 องศา |
| หันไปทางเหนือ / ใต้ / ตะวันออก / ตะวันตก | หันไปทิศที่ระบุ |
| หันไปทางเสียง / จับทิศเสียง | หันเข้าหาศัตรูที่ได้ยิน |
| หนี / วิ่งหนี | พยายามหนีจากการต่อสู้ |

## ฟังและสำรวจ

| พูดว่า | ผล |
| --- | --- |
| สำรวจ / ฟังรอบตัว / มีอะไรบ้าง | บรรยายห้อง จุดสังเกต และทางออกใหม่ |
| ฉันอยู่ที่ไหน / บอกตำแหน่ง | วิสป์สรุปตำแหน่งและสิ่งรอบตัว |
| ระลอกสำรวจ | คาถาโซนาร์ เผยผังห้องและของที่ซ่อนอยู่ (ใช้พลังกังวาน) |
| ไปทางไหนต่อ / วิสป์ช่วยที | บอกภารกิจปัจจุบันและเส้นทางไปต่อ |
| พาไปถ้ำสะท้อน / นำทางไปหอระฆัง | นำทางไปยังสถานที่ที่ระบุ |

## สถานะและของ

| พูดว่า | ผล |
| --- | --- |
| สถานะ / พลังชีวิตเหลือเท่าไหร่ | อ่านค่าพลัง ตำแหน่ง ทิศ และภารกิจ |
| ย่าม / มีอะไรในย่าม | อ่านรายการของ |
| ดูคาถา / มีคาถาอะไรบ้าง | อ่านรายชื่อคาถาที่ร่ายได้ |
| เก็บของ / หยิบ | เก็บของในห้อง |
| ใช้ขวดน้ำกังวาน / ดื่มน้ำกังวาน | ใช้ของในย่าม |
| บันทึกเกม / โหลดเกม | บันทึกและโหลดความคืบหน้า |
| เริ่มใหม่ | ฟื้นคืนหลังล้ม หรือเริ่มการเดินทางใหม่ |
| เงียบ / หยุดพูด | หยุดเสียงอ่านทันที |
| พูดอีกครั้ง / ไม่ได้ยิน | อ่านประโยคล่าสุดซ้ำ |
| ช่วยด้วย / เล่นยังไง | อ่านวิธีเล่นทั้งหมด |

## ร่ายคาถา

พูด **ชื่อคาถา** ออกมาตรง ๆ หรือพูดเป็นประโยคก็ได้ เช่น "ขอร่ายเพลิงกังวานหน่อย"

`เพลิงกังวาน` · `สายลมวน` · `ผลึกจันทร์` · `แสงสมาน` · `ระลอกสำรวจ` ·
`ค้อนกังวาน` · `วิรัลประกาย` · `ธารเงา` · `รากพิภพ` · `เสียงสะกด`

## พูดคุย

| พูดว่า | ผล |
| --- | --- |
| คุยกับยายมาลี / คุยกับมาลี | เริ่มสนทนา (พูดชื่อย่อได้) |
| (ระหว่างสนทนา) พูดอะไรก็ได้ | ตัวละครตอบตามบุคลิกและสิ่งที่ตัวเองรู้ |
| ลาก่อน / ขอบคุณ | จบการสนทนา |
| วิสป์ มหาเงียบคืออะไร | ถามวิสป์เรื่องโลก ตัวละคร คาถา หรือศัตรู |
